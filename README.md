# Logistics Data Analysis (Week 3)

Simulated 6,000-shipment logistics dataset with validation, EDA and 8 visualizations.

- `Logistics_Analysis_Report.docx` - full report
- `logistics_analysis.py` - simulation, cleaning, EDA, charts, scenarios (seed 42)
- `logistics_clean.csv` - cleaned dataset (5,842 rows)
- `figures/` - the 8 charts used in the report

Run: `pip install pandas numpy matplotlib seaborn scipy` then `python logistics_analysis.py`
